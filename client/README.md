# Finz Finance — Client Frontend

The client is a modern single-page application built with React 19, TypeScript, Vite, and Tailwind CSS.

For complete documentation, architecture diagrams, and setup instructions, see the root [README.md](../README.md).

### Scripts
* `npm run dev`: Launch the Vite development server with HMR.
* `npm run build`: Type-check with TypeScript and build for production.
* `npm run preview`: Preview the production bundle locally.
